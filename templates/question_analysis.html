Exam question analysis

Each prompt is assigned two 4-point research codes (essay question quality; grade-level appropriateness) by comparing Hugging Face sentence embeddings to fixed rubric tiers — the same structure as quantitative coding for thematic analysis. Supplementary 0–10 relevance, quality, and humor signals are also shown for context.

Tools used: FastAPI + SQLAlchemy for retrieval, sentence-transformers (Hugging Face, PyTorch backend) for semantic coding, pandas for grouped summaries, and Chart.js for interactive dashboard widgets.
